# DashForge Feature Tracker

## Dashboard customization

- [D] Dedicated color-customization section for chart areas, dashboard background, KPI backgrounds, header, footer, and text.
- [D] Built-in themes (for example, light and dark) so users can start from a preset instead of configuring every color.
- [D] Logo support.
- [D] Optional subtitle displayed directly below the dashboard title.
- [D] Font selection.
- [D] Customizable footer content.
- [D] Optional timestamp in the footer (`True` / `False`).
- [D] Hide the toolbar when desired.

## Layout and content

- [D] Let users choose the number of charts per row, up to three. Total charts 6: [1, 2, 2, 1]
- [D] Let users configure individual chart sizes. max 100 per row. [None, [[30,150], [60,100]], None, [100]]
- [D] Use sensible defaults whenever an option is omitted.
- [ ] Customize which charts allow having the maximize button.

## Data and output

- [ ] Data-table support.

## Decisions / notes

- Plotly is the primary charting engine through Dash.
- Plotly already provides chart image export; dashboard-level image export is the useful addition.
- No dashboard description for now, to preserve spacing.
- No user watermark for now because the footer is customizable.
- A DashForge watermark on the far-left side of the footer is under consideration.
- Dashboard-width controls are not currently a priority.
- Rounded corners are optional and not currently necessary.
- PDF and PowerPoint export are not currently priorities.
- Search is mainly valuable for the CSV-tab use case.
